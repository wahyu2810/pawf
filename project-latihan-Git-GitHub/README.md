# 📌 Deskripsi Project

**Project Latihan Git** merupakan proyek sederhana yang dibuat untuk mempelajari penggunaan **Git** dan **GitHub** sebagai sistem **Version Control System (VCS)** dalam proses pengembangan aplikasi web.

Repository ini berisi contoh **aplikasi web kalkulator sederhana** yang dibuat menggunakan **HTML, CSS, dan JavaScript**. Selain itu, project ini juga digunakan sebagai media latihan untuk memahami alur kerja Git seperti:

* Commit
* Push
* Branch
* Merge
* Version Tracking

Project ini juga menampilkan implementasi **kalkulator web dengan tampilan menyerupai kalkulator meja (desk calculator)**.

---

# 🎯 Tujuan Project

Tujuan utama dari project ini adalah untuk memahami konsep dasar pengelolaan kode menggunakan **Git dan GitHub**, diantaranya:

* Inisialisasi repository menggunakan Git
* Menambahkan perubahan kode ke staging area
* Melakukan commit perubahan kode
* Menghubungkan repository lokal dengan GitHub
* Menggunakan branch untuk pengembangan fitur
* Melakukan merge antar branch
* Mengelola perubahan kode secara terstruktur

---

# 🧮 Fitur Aplikasi

Aplikasi kalkulator dalam project ini memiliki beberapa fitur dasar, antara lain:

* Operasi matematika dasar

  * Penjumlahan (+)
  * Pengurangan (-)
  * Perkalian (×)
  * Pembagian (÷)

* Tombol fungsi tambahan

  * AC (All Clear)
  * CE (Clear Entry)
  * Persen (%)

* Tampilan kalkulator menyerupai **kalkulator meja kantor**

* Antarmuka sederhana dan mudah digunakan
